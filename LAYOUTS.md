## Визуальные схемы

```
1 — Сетка 2×2 (16:9)
┌──────────────┬──────────────┐
│     16:9     │     16:9     │
├──────────────┼──────────────┤
│     16:9     │     16:9     │
└──────────────┴──────────────┘

2 — Журнал (4:3)
┌──────────────────┬────────┐
│                  │  4:3   │
│      4:3         ├────────┤
│                  │  4:3   │
│                  ├────────┤
│                  │  4:3   │
└──────────────────┴────────┘

3 — Баннер (21:9 + 16:9)
┌──────────────────────┬──────┐
│       21:9           │16:9  │
├──────────────────────┼──────┤
│       21:9           │16:9  │
└──────────────────────┴──────┘

4 — Портрет + квадрат (3:4 + 1:1)
┌──────────────┬──────────────┐
│    3:4       │     1:1      │
└──────────────┴──────────────┘

5 — 3 портрета (9:16)
┌────────┬────────┬────────┐
│  9:16  │  9:16  │  9:16  │
└────────┴────────┴────────┘

6 — 4 панели (3:2 + 2:1)
┌──────────────┬────────────────┐
│    3:2       │     2:1        │
├──────────────┼────────────────┤
│    3:2       │     2:1        │
└──────────────┴────────────────┘

8 — Герой+два (4:3 + 1:1×2)
┌──────────────┬──────┐
│              │ 1:1  │
│     4:3      ├──────┤
│              │ 1:1  │
└──────────────┴──────┘
```

| Диалог двух-трёх персонажей | 8, 4                 |
| Эмоциональный момент        | 5 (вертикаль)        |
| Экшен, динамика             | 6, 3                 |
| Финальный акцент            | Fullscreen           |
